# Política de segurança

## Dados que não devem ser publicados

Não abra issues, commits ou pull requests contendo tokens, cookies, credenciais, cURL autenticado, URLs privadas, dados de clientes ou respostas de sistemas internos.

## Antes de publicar

Faça uma busca no repositório e também no histórico Git por segredos e referências corporativas. Se um segredo já tiver sido commitado, apenas removê-lo do commit atual não é suficiente: revogue/rotacione a credencial e remova-a do histórico antes da publicação.

## Escopo

Esta versão é demonstrativa. A integração privada original não faz parte do repositório público.
